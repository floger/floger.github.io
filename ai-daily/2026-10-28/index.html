AI 日报：2026-10-28

采集于 2026-10-28 · 共 10 条 · 覆盖北京时间 10 月 27 日 18:00 至 10 月 28 日 18:00；部分条目为过去 72 小时内的持续进展；厂商自报、论文结果与报道推断已单独标注

1. OpenAI 发布 GPT-6.1 Terra：把计算机使用能力推向更低成本
OpenAI 10 月 26 日发布 GPT-6.1 Terra，定位为更快、更高效的计算机使用模型，并称标准 API 价格低于上一代 Terra 和 GPT-6.1 Sol。官方还公布了 Agents’ Last Exam、MMMU-Pro、OSWorld 2.1 和 Terminal-Bench 4.0 等内部或合作评测结果；这些数字属于厂商披露，不等同于独立复测。
💡 计算机使用模型的竞争正在从“能不能操作”转向“单位任务成本、速度、权限和失败恢复”。
🔗 OpenAI 官方发布；OpenAI 新闻索引
2. OpenAI 与 Oracle 扩大合作，企业应用和数据进入 ChatGPT 工作流
OpenAI 10 月 27 日宣布与 Oracle 扩大合作：双方计划把 Oracle 应用和数据带入 ChatGPT，并推出 Oracle AI Workspace、AI Security Mesh、SMB Bundle 和 App Composer 等新产品方向。OpenAI 引用 Oracle 数据称，其已有 13 万名活跃 ChatGPT 用户和超过 9.5 万名活跃 Codex 用户；合作目标和产品规划不代表所有功能已经普遍可用。
💡 企业 Agent 的关键入口正在从独立聊天窗口转向 ERP、采购、财务和权限系统，数据边界与审批链会决定真实落地。
🔗 OpenAI 官方公告；OpenAI 与 Oracle 合作背景
3. OpenAI 公布三项 AI 科研发现，尝试让外部学术群体接管解释与验证
OpenAI 10 月 26 日宣布在调和分析、复杂性理论和量子场论方向发布三项新发现，并把数学、计算机科学和物理结果分别交给外部专家群体组织解释或决定材料发布方式。公司称数学结果已形成 Lean 形式化证明并公开部分材料；这些结果仍需要独立研究者核验，不能直接当作已完成的学术共识。
💡 AI 科研的瓶颈开始从“模型能否生成候选结果”转向“谁来解释、形式化、复现和分配学术信用”。
🔗 OpenAI 官方研究公告；OpenAI math 开源仓库
4. GitHub Universe 2026 开幕，开发者平台把主题聚焦到 Agentic Era
GitHub Universe 2026 于 10 月 28—29 日在旧金山举行。GitHub 官方将本届活动定位为围绕人、工具、集成和 Agent 的统一软件开发工作流，并安排产品演示、开发者实践、开源社区和安全议题。活动预告本身不代表所有发布功能已正式 GA。
💡 编程 Agent 的竞争焦点正从单次补全转向仓库级协作、权限控制、审查和可复现交付。
🔗 GitHub 官方活动说明；GitHub Universe 2026 官方站
5. Google AI Quest 推出“人脑地图”主题挑战，教育场景继续吸收 AI 探索式学习
Google 10 月 26 日在教育产品博客发布新的 AI Quest，主题为绘制人脑地图，面向学习者提供探索式任务。页面强调通过 AI 和互动内容帮助用户理解复杂主题；它是教育产品活动，不应被解读为新的脑科学研究结论。
💡 AI 教育产品正在从问答辅导转向任务化探索，内容质量、事实校验和学习效果比模型新奇感更重要。
🔗 Google 官方博客；Google AI 新闻索引
6. 研究显示：AI Agent 能完成科研工程，但仍难以推进开放式研究问题
arXiv 论文《Can AI agents conduct open-ended AI research?》提出 shadow evaluations：让 Agent 接手两篇未发表 NeurIPS 2026 论文的核心研究问题，再由原作者评估。论文报告 Agent 能在六天内完成工程工作，但未能实质推进研究问题，并归纳出研究判断、创新性、死路回退、资源意识和指令漂移等失败模式。该结果是两项案例的早期证据，不是对所有 Agent 的普遍定论。
💡 这提醒团队不要用“能写代码、能跑实验”替代对研究判断和问题选择能力的评估。
🔗 arXiv 原论文；论文 PDF
7. 科大讯飞 Spark X2.6 等产品动态进入公开披露，国产模型继续强化行业化叙事
科大讯飞相关公告披露 Spark X2.6 及一批新产品动态，覆盖模型能力和行业应用方向。公开材料中的性能、场景和商业化表述主要来自公司或合作方，本文不把厂商宣传指标当作独立评测结论。
💡 国内模型竞争已不只是参数和榜单，教育、办公、政企和行业交付能力将更直接影响采购。
🔗 公开公司公告转载；科大讯飞官网
8. 腾讯持续更新 AI 产品与基础设施信息，企业侧更看重模型接入和治理
腾讯新闻中心持续披露混元、腾讯云及相关 AI 产品的企业服务动态。公开信息显示，腾讯仍在把模型能力与云服务、业务系统和开发工具结合；具体功能、地区可用性和商业条件应以各产品官方文档为准。
💡 国产云厂商的差异化越来越依赖模型、数据、权限、运维和行业交付的一体化，而不只是模型单点能力。
🔗 腾讯新闻中心；腾讯混元产品页
9. AI 科研发布机制出现新实验：原始模型输出与学术解释被明确拆开
OpenAI 的科研公告把“模型产生的原始结果”和“外部学者对结果的解释、证明、写作与复现”分成不同环节，并提出透明、无学术署名、不要求保密和保持独立等原则。该机制仍处于试验阶段，外部群体如何参与、如何审查和如何形成正式论文仍待观察。
💡 对 AI 生成科学结果而言，发布论文只是起点，证据链、形式化证明和独立复现才是可用性门槛。
🔗 OpenAI 原始公告；Lean 形式化材料
10. GitHub 把“人、Agent、代码”放进同一开发叙事，安全保护成为配套约束
GitHub 在 Universe 预告和 AI/ML 内容中把 Agent 协作、开发者工作流和软件安全放在同一产品叙事下；其安全栏目同时强调，随着软件产出速度提高，秘密保护等基础安全能力也必须同步扩展。这里是平台方向与产品内容的综合，不代表所有能力都已在所有套餐上线。
💡 编程 Agent 真正进入团队后，秘密扫描、权限边界、审查记录和回滚能力会与生成质量同等重要。
🔗 GitHub Universe 说明；GitHub 安全文章
