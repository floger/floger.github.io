AI 日报：2026-06-03

采集于 2026-06-03 18:00 CST · 共 10 条

1. OpenAI Codex changelog：GPT-5.3-Codex 已覆盖 Codex 主要入口，API 将随后开放
OpenAI Developers 的 Codex changelog 显示，GPT-5.3-Codex 已面向付费 ChatGPT 计划开放，可在 Codex app、CLI、IDE 扩展和 Codex Cloud 网页端使用，API access 将在随后提供。
💡 这说明编码模型正在从单一聊天能力升级为跨本地、云端和 IDE 的完整软件工程 Agent 入口。
🔗 OpenAI Developers
2. GitHub Copilot SDK 正式 GA，开放 Copilot 背后的 Agent runtime
GitHub Changelog 6 月 2 日称 Copilot SDK is now generally available，开发者可直接调用 Copilot 背后的 agent runtime，包括 planning、tool invocation、file edits、streaming 和 multi-turn sessions。
💡 Copilot 从产品能力变成可编程底座，会让更多应用直接复用成熟的代码 Agent 编排层。
🔗 GitHub Changelog
3. GitHub Copilot 个人版 auto model selection 开始纳入 evaluation models
GitHub Changelog 6 月 1 日更新称，Copilot 面向 individual non-enterprise users 提供 evaluation models，并且这些模型可能通过 Copilot auto model selection 被调用，用户可选择关闭。
💡 模型灰度进入自动路由后，开发者需要关注稳定性、成本和企业合规之间的取舍。
🔗 GitHub Changelog
4. Alphabet 计划融资 800 亿美元支持 AI 基础设施扩张
TechCrunch 6 月 1 日报道称，Google 母公司 Alphabet 计划筹集 800 亿美元，用于支持其规划中的大规模 AI infrastructure buildout。
💡 头部公司继续把 AI 竞争押注在算力和数据中心资本开支上，基础设施约束仍是模型竞争核心变量。
🔗 TechCrunch
5. NVIDIA 推动面向 Microsoft、Dell、HP 的 AI Agent PC，切入 2000 亿美元 CPU 市场
TechCrunch 6 月 1 日报道称，NVIDIA 正通过 Microsoft、Dell 和 HP 的 AI agent PCs 追逐约 2000 亿美元 CPU market。
💡 AI Agent 从云端走向个人电脑，会改变端侧算力、PC 采购和企业桌面自动化的竞争格局。
🔗 TechCrunch
6. VivaTech 2026 成为欧洲 AI 战略展示窗口
TechCrunch 6 月 2 日报道称，VivaTech 2026 被视为观察 Europe’s AI strategy 的重要场景，欧洲试图在美国与中国之外提出另一种 AI 发展模型。
💡 AI 竞争不只看模型能力，也会越来越受地区监管、产业政策和主权算力叙事影响。
🔗 TechCrunch
7. JetBrains 在 Hugging Face 发布 Mellum2：12B MoE 模型面向多模型调用工作流
Hugging Face Blog 6 月 1 日发布 JetBrains Mellum2，介绍其为 12B Mixture-of-Experts model，并强调现代 AI 系统中的 routing、retrieval、summarization、planning、validation 和 tool use 等多次模型调用场景。
💡 IDE 厂商继续自研小而专的模型，说明 AI 编程竞争正在深入到延迟、路由和工具链成本优化。
🔗 Hugging Face / JetBrains
8. NVIDIA Cosmos 3 登上 Hugging Face，定位开放 Physical AI Omni-model
Hugging Face Blog 6 月 1 日发布 NVIDIA Cosmos 3，称其为面向 Physical AI 的开放 Omni-model，并提供 Nano 等不同部署规格。
💡 机器人、仿真和物理世界推理正在成为多模态模型的下一轮重点应用场景。
🔗 Hugging Face / NVIDIA
9. Qwen3.7-Plus 发布，主打 Multimodal Agent Intelligence
Qwen 官方博客显示，Qwen3.7-Plus 于 2026 年 6 月 1 日发布，主题为 Multimodal Agent Intelligence，并提供简体中文翻译。
💡 国内模型继续把视觉、语言、工具调用和长任务能力合并到统一 Agent 基座中，值得跟踪产品化速度。
🔗 Qwen
10. arXiv：Agent libOS 提出面向长运行 LLM Agent 的类 Library-OS runtime
arXiv 论文 Agent libOS: A Library-OS-Inspired Runtime for LLM Agents 描述了一个运行在常规操作系统之上的 Agent runtime substrate，用于支持状态维护、子任务 fork、等待外部事件和请求人类授权等长运行 Agent 行为。
💡 Agent 工程化的瓶颈正在从模型转向运行时，谁能管理状态、权限和失败恢复，谁就更接近生产可用。
🔗 arXiv
