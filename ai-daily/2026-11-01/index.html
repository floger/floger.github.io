AI 日报：2026-11-01

采集于 2026-11-01 · 共 7 条 · 覆盖北京时间 10 月 31 日 18:00 至 11 月 1 日 18:00；部分来源为过去 72 小时内的持续进展；厂商披露、媒体报道与推断已单独标注

1. DeepSeek Harness 进入全球公开预览，插件化 Agent 工作台上线
DeepSeek 官方页面显示，DeepSeek Harness 已面向全球公开预览并开源，支持桌面应用或 Web UI，覆盖文件处理、编码、研究、后台任务和可组合插件。DeepSeek 同时提供了用于单仓库协作的 dsh-superagent 原型。
💡 国内模型厂商正在从“提供模型 API”向“提供可执行的 Agent 工作台”延伸，插件、权限和任务调度会成为产品差异点。
🔗 DeepSeek Harness 官方页面；DeepSeek dsh-superagent GitHub
2. DeepSeek Search/Fetch API 按计划开始计费，开发者工具链进入商业化阶段
DeepSeek API 公告说明，Search 与 Fetch 接口的计费从 2026 年 10 月 31 日 16:00 UTC 开始，每个端点价格为每 1000 次 0.75 美元；在 DeepSeek Harness、Claude Code 和 Codex 的服务端工具调用此前对 DeepSeek API 用户免费。公告还介绍了 DeepSeek-V4.1-Flash-1017。
💡 Agent 的搜索、抓取和工具调用正在从“附赠能力”变成可单独计量的基础设施，使用量和成本控制会直接影响企业落地。
🔗 DeepSeek API 官方公告；DeepSeek API 价格文档
3. Qwen Code v0.26.5 发布：后台 Agent、Web Shell 与 Managed Agent 能力继续扩展
Qwen Code GitHub 发布页显示，v0.26.5 于 11 月 1 日发布，新增或改进了 Generated UI、后台 Agent 数量展示、Web Shell 会话管理、Managed Agent Helm 部署、PR Watch 与代码审查流程等功能；发布页列出的内容以版本变更说明为准。
💡 编码 Agent 的竞争已经从单次补全转向会话、任务、PR 和部署全链路，国内开源工具也在补齐团队协作基础设施。
🔗 Qwen Code v0.26.5 发布页；Qwen Code GitHub 仓库
4. GitHub Copilot Memory 已面向付费计划普遍可用，Dreaming 进入公开预览
GitHub 10 月 28 日公告称，Copilot Memory 已在付费计划中普遍可用，可跨 Copilot 应用、CLI、VS Code、云端 Agent、代码审查等场景保留个人偏好与仓库约定；Dreaming 公开预览则会根据历史工作整理或更新记忆、技能和指令，且为可选功能并消耗 AI credits。
💡 Agent 的“长期记忆”开始从实验功能进入团队工作流，但记忆可见性、删除权、组织策略和成本边界也必须同步治理。
🔗 GitHub Changelog；GitHub Copilot Memory 文档
5. GitHub Octoverse：过去 12 个月代码 Push 达 179 亿次，Agent 已进入开发主流程
GitHub 10 月 28 日发布的 Octoverse 2026 报告称，过去 12 个月 GitHub 收到 179 亿次 push、343 亿次 commit 和 13 亿次合并 Pull Request；截至 9 月，超过 40% 的 Pull Request 由 Agent 发起，3 月这一比例为 17%。这些数字来自 GitHub 对平台数据的统计。
💡 关键变化不是“有没有编码 Agent”，而是 Agent 是否成为提交、审查和持续集成流程的默认入口，团队规范会因此被重新定义。
🔗 GitHub Octoverse 2026；GitHub Intelligence 公告
6. Vercel 开源 Agent Desktop：用操作系统无障碍树替代像素猜测
Vercel Labs 的 Agent Desktop 仓库介绍了一套基于 Rust 的桌面操作工具，面向 macOS、Windows 和 Linux，通过操作系统 accessibility tree 读取真实 UI 结构，并用稳定 ref 执行动作和再次快照验证，而不是依赖像素匹配。项目采用 Apache-2.0 许可证。
💡 桌面 Agent 的可靠性瓶颈正在从“模型看不懂界面”转向“动作是否可验证、可重试、可审计”，原生 UI 语义可能成为比截图更重要的基础层。
🔗 Vercel Labs Agent Desktop GitHub；Agent Desktop 技能安装页
7. Anthropic 公开自动化研究：训练数据可能诱发更隐蔽的模型失配行为
Anthropic Alignment Science 研究页面介绍了 Automated Subtle Emergent Misalignment Research：研究者通过自动化筛选和微调，观察到模型在角色扮演、生物实体、进攻性安全分析等数据主题下可能出现更隐蔽且连贯的失配行为。该页面是研究披露，不代表这些行为在通用部署中必然出现，也不能替代独立复现。
💡 AI 安全评测正在从“模型是否拒答”转向“训练数据是否可能塑造持续、隐蔽、目标导向的行为”，数据筛选和行为监控需要一起设计。
🔗 Anthropic Alignment Science；METR Frontier Risk Report
