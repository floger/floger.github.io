AI 日报：2026-09-13

今日重点：开源生态继续把 AI 能力推向可部署的 Agent、推理和工作流；国内团队也在持续更新多模态模型与工程文档。信息截至 18:00（中国标准时间）。本期事实均来自项目官方发布页或官方博客。

1. OpenAI Python SDK 3.13.0 加入 Agents API 支持
OpenAI 官方 SDK 仓库发布 v3.13.0，变更说明列出的核心功能是新增 Agents API。
💡 值得看：Agent 能力开始进入主流 SDK，应用开发者需要关注 API 抽象而不只是模型调用接口。
🔗 GitHub 官方 Release（🟢 一手来源）
2. Ollama 0.34.0 支持在 ChatGPT Desktop 中使用本地模型
Ollama 官方 Release 说明称，macOS 用户现在可以在 ChatGPT Desktop 中直接使用 Ollama 模型；该版本同时改进结构化输出性能。
💡 值得看：本地模型与桌面 AI 应用的连接更短，隐私、成本和模型可控性因此更容易进入普通工作流。
🔗 Ollama 官方 Release（🟢 一手来源）
3. vLLM 0.29.0 将 Model Runner V2 设为默认
vLLM 官方 Release 说明称，0.29.0 包含 594 个提交、277 位贡献者，并将 Model Runner V2 设为所有模型的默认运行器，同时加入 KV Cache 自动 sizing 等能力改进。
💡 值得看：推理框架的默认执行路径变化，可能比单个模型发布更直接地影响线上吞吐、显存和运维成本。
🔗 vLLM 官方 Release（🟢 一手来源）
4. Hugging Face 展示用 Gradio Workflow 重建 AUTOMATIC1111
Hugging Face 官方博客发布教程，展示如何使用 Gradio Workflow 重建 AUTOMATIC1111 类图像生成界面，并连接模型、工作流和推理提供商。
💡 值得看：工作流编排正在成为连接开源模型与可用产品界面的低门槛方式。
🔗 Hugging Face 官方博客（🟢 一手来源）
5. IBM Research 发布 Granite Time Series PatchTST-FM-r2
Hugging Face 官方博客介绍 IBM Research 发布的 Granite Time Series PatchTST-FM-r2，并强调其面向商业使用的许可证。
💡 值得看：基础模型不只服务文本和图像，时间序列模型的许可证与部署条件同样决定企业能否采用。
🔗 Hugging Face / IBM Research 官方博客（🟢 一手来源）
6. Hugging Face 讨论“只拒绝危险子集”的安全策略
Multiverse Computing 在 Hugging Face 官方博客发布《Safety for Whom?》，讨论模型是否应拒绝整个主题，还是只拒绝主题中的高风险子集。
💡 值得看：安全策略的关键不只是拒答率，而是能否保留正常知识使用并精确拦截高风险请求。
🔗 Hugging Face 官方博客（🟢 一手来源）
7. NeoMME 面向多模态与多语言场景优化编码器
Hcompany 在 Hugging Face 官方博客介绍 NeoMME，定位为高效的多模态原生、多语言编码器。
💡 值得看：编码器仍是检索、分类和跨模态理解的基础组件，效率与语言覆盖会直接影响端到端成本。
🔗 Hugging Face / Hcompany 官方博客（🟢 一手来源）
8. Funes 提出“由自己拥有”的 Coding Agent 记忆
Hugging Face 官方博客发布 Funes，主题是为 Coding Agent 提供用户可拥有、可控制的记忆机制。
💡 值得看：Agent 记忆一旦可迁移、可审计，长期协作就不必被锁在单一产品或供应商里。
🔗 Hugging Face 官方博客（🟢 一手来源）
9. BenchMIRT 追问大模型基准到底测量了什么
Allen Institute 在 Hugging Face 官方博客介绍 BenchMIRT，专门讨论 LLM 基准测试指标与实际能力之间的测量关系。
💡 值得看：当模型排行榜越来越拥挤，先弄清基准测到的对象，才能避免把分数误当成真实生产力。
🔗 Hugging Face / Allen Institute 官方博客（🟢 一手来源）
10. OpenBMB MiniCPM 仓库更新采样参数文档，减少重复输出
OpenBMB MiniCPM 官方仓库在 9 月 12 日提交更新，调整 README 及相关文件中的采样参数说明，目标是避免生成重复输出。
💡 值得看：国内开源模型的可用性改进不只靠参数规模，默认配置和文档质量同样决定开发者体验。
🔗 OpenBMB 官方 GitHub 提交（🟢 一手来源）
