1. 腾讯 WeMM-Video 公开多规格音视频理解模型，支持带原声的视频输入
腾讯微信视觉团队的 WeMM-Video 技术报告于 11 月 19 日 16:58 UTC 上传，即北京时间 11 月 20 日 00:58。系列覆盖 2B、4B、9B 稠密模型及 35B-A3B MoE，接收文本、图片、音频和视频并输出中英文文本，可将视频帧与原始音轨联合分析，提供直接回答与思考两种模式。官方仓库与模型卡提供权重、量化变体和推理说明；训练约 1.2 万亿多模态 token、评测超过 120 项基准及领先结论均为团队自报。
值得看：面向会议、教程或设备录像，不必先把原声完全压成文字再看画面。先拿有背景噪声、时间戳与声画不一致的真实片段测试；部署需核对各权重许可和运行时补丁，并审计 trust_remote_code，不能把模型规格名直接当显存需求。
腾讯官方仓库与部署说明 · 作者报告与提交时间（北京时间 11 月 20 日） · 腾讯官方 2B 模型卡
2. GPT-Live-1.1 进入 API：语音按分钟计费，静默待机与后端工具另算
OpenAI API 更新日志将 GPT-Live-1.1 发布标为 11 月 19 日，强调多语言发音、口音一致性与转写改善；开发者可在 Live 会话配置中使用 gpt-live-1.1。模型支持一边说一边听，并通过自然语言配置何时委派后端推理或工具工作。模型文档列出活跃每分钟 0.05 美元、standby 每分钟 0.02 美元；低待机费率适用于推理暂停的 WebRTC 会话，后端模型及工具用量单独计费。
值得看：语音助手的成本不只由说话时长决定，还包括等待与后端任务。评估电话或陪练应用时，应分别记录活跃、待机、委派用量及打断体验，不要把待机单价写成整通电话的统一费用。
OpenAI 官方带日期更新日志（11 月 19 日） · 官方模型能力、价格与计费边界
3. Gemini Mac 版推出电脑操作：独立后台窗口，不占用主光标
Google 11 月 19 日宣布 Gemini Mac 应用开始推送 computer use，可操作本地文件、桌面应用与网页。任务在隔离后台窗口内运行，聊天提供实时预览；用户选择可访问应用、随时暂停并批准关键动作。当前以英语面向美国的 Google AI Plus、Pro、Ultra 用户，要求 Apple Silicon、macOS Sequoia 15.0 及以上，以及 18 岁以上个人账号，并非所有地区或免费账号均可使用。
值得看：比演示能点多少按钮更重要的是执行环境和授权边界。可以用“从本地 PDF 取字段—填写表单—停在提交前”等流程测试可中断性，先验证授权与恢复，再扩大到有支付或外发风险的任务。
Google 官方公告、使用场景与地区限制（11 月 19 日）
4. Genie 4 开放开发者 API，与上期消费者体验上线不是同一进展
Google 11 月 19 日宣布，Genie 4 经 Interactions API 接入 Gemini API，并在 Google AI Studio 提供开发者入口。官方介绍可由文本、参考图或两者生成连续的 720p、24fps 交互世界，配合同步原生音频，用键盘及实时文本改变场景，输出包含 SynthID 水印。上期报道的是 Project Genie 对 Ultra 用户开放；本期新增的是开发者调用渠道。公告正文未列具体单价，本期不猜价格。
值得看：可以开始研究如何把世界模型接入交互原型，而不只是观看成片。先检查会话连续性、操作延迟、配额和计费，再考虑训练环境用途；官方列举机器人训练场景，不等于已经证明具备可信物理仿真能力。
Google 官方 API 公告（11 月 19 日）
5. Gemini API 工具检索进入预览：参数 schema 按需加载，工具执行仍归应用
Google 11 月 19 日在 Interactions API 预览 Tool Retrieval。配置 tool_search 和 defer_loading 后，模型先看到工具名称与描述，需要时才加载完整参数 schema；支持远程 MCP，并提供客户端自管检索方式。官方称支持 Gemini 3.6 及后续模型，功能不单独收费，但工具搜索产生的 token 与加载后的 schema 仍按模型费率计费。模型生成 function_call 后，仍由应用代码执行实际操作。
值得看：工具越多，不一定越该把所有参数塞进每轮提示。可先把低频工具延迟加载，比较总输入量、选错工具率及往返次数；检索不是权限控制，退款、发信等动作仍须经过独立授权。
Google 官方实现示例、计费与适用模型（11 月 19 日）
6. LangSmith Tool Gateway 公测：把工具权限、身份与审计从 Agent 提示中移出来
LangChain 11 月 19 日推出托管的 LangSmith Tool Gateway Public Beta。团队可注册 MCP 服务器或使用内置连接，将允许的工具组成单个 kit URL；调用可使用用户本人或 Agent 服务身份，并配置拒绝及审批策略。工具 trace 记录工具、服务器、身份、结果和耗时；官方称不记录工具传入传出数据。组织级审计日志属于 Enterprise 功能，不能把公测与全部企业功能免费画等号。
值得看：凌晨运行的库存 Agent 和员工主动查询 Agent 不应共享同一套默认凭证。可借鉴其“工具白名单—调用身份—高风险审批—审计记录”四项检查，不必为验证这一思路立即迁移到托管平台。
LangChain 官方产品说明与企业功能边界（11 月 19 日）
7. OpenAI 复盘 Performance Factory：根因要被反驳测试，部署后还要验证恢复
OpenAI 11 月 19 日介绍内部 Codex 性能工程工作流：告警生成持久任务，Agent 调查、独立会话挑战诊断、提出 PR，工程师决定合入与部署，随后 Agent 核对指标是否恢复。官方称三个多月跟踪超过 1,700 次调查、定位超过 600 起根因；人工抽查 100 个根因建议，70% 判为准确，其余仍需完善或没有充分建立因果关系。以上为公司工程报告，不是外部评测，也不是全部修复已无人审批。
值得看：最可复制的是反证与验收，而不是再加几个并行 Agent。把“回滚后是否恢复”“未暴露请求是否正常”“上线后是否回到基线”写进任务验收，能避免有解释、有 PR 就宣布问题解决。
OpenAI 官方工程复盘、误差与人工边界（11 月 19 日）
8. 蚂蚁 Code World Model 2.0：上游管世界状态，视频模型负责受控渲染
Inclusion AI（蚂蚁）、西湖大学和浙江大学团队的 Code World Model 2.0 论文于 11 月 17 日提交、18 日更新。Invoker-Render 以结构代理、外观参考和文本为接口，结合双向创作模型与四步因果流式模型；约 200 小时对齐数据配合 Progressive Forcing，逐步从干净历史过渡到自生成历史训练。作者报告了 30 分钟赛车生成案例，同时在结论中承认，离开活动上下文的视觉细节仍会被逐步淘汰，持久记忆与动态细节切换尚待探索。
值得看：这条路线没有要求模型同时学会一切物理规则，而是让显式状态与视觉生成各司其职。做可交互内容时，可以先让代码保证规则，再测试画面是否跟随；长演示不能直接证明重访场景或多人实体永久一致。
作者论文完整正文、方法与局限（11 月 18 日版本） · 提交与更新记录
9. ROCm 10.2 更新推理部署栈：新版 vLLM、SGLang 与存储到 GPU 路径
AMD 11 月 18 日介绍 ROCm 10.2，推理构建升级到 vLLM 0.32.0、SGLang 0.5.21，新增 PyTorch 2.15 wheels，并继续优化单机多 GPU 通信。hipFile 与 AMD Infinity Storage 扩展 LVM、mdraid 支持，提供 PyTorch 存取接口；InferaSim 利用少量实测 GPU 运行估计配置的显存、延迟与副本需求。官方镜像为部分 Radeon、Ryzen AI 场景集成 AITER，首次使用仍可能发生内核编译，不能泛化为任意硬件免调试。
值得看：对开放权重模型部署，框架、驱动、通信和权重载入往往比换模型名更影响交付。升级前用现有模型跑冷启动、长上下文和多卡回归，尤其检查依赖打包变化；本期未安装或运行新版。
AMD 官方版本说明及软硬件条件（11 月 18 日）
10. Architect Labs 展示 AI 设计 CPU Frostbite，4.59 倍能效仍是限定对照的流片前结果
Architect Labs 11 月 18 日发布 Frostbite 技术博客，称 AI 系统联合迭代编译器、指令集、微架构、RTL、验证及最终 GDS，以 interaction nets 暴露计算依赖。公司在 25 项预先选定工作负载（15 项留作最终评估）上，报告相对一款双发射顺序执行 CPU 核心的几何平均性能功耗比为 4.59 倍。正文明确功耗仍为 pre-silicon 数据，并因法律原因未披露对照 CPU 型号；本期不将其写成芯片量产或实测全面领先。
值得看：工程价值在于用可机检的形式化契约约束跨层 Agent 修改，以及持续对齐快速模型和 RTL 的估算。写作时必须把设计文件完成、流片、回片和实测区分开，不能让一个倍率跨越所有验证阶段。
Architect Labs 一手方法、对照条件与后续计划（11 月 18 日）
