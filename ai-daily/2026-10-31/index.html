AI 日报：2026-10-31

采集于 2026-10-31 · 共 7 条 · 覆盖北京时间 10 月 30 日 18:00 至 10 月 31 日 18:00；部分来源为过去 72 小时内的持续进展；厂商披露、媒体报道与推断已单独标注

1. Gemini 应用开始支持直接创建和编辑文件
Google 介绍 Gemini 应用中的文件生成与编辑能力，用户可以从对话直接创建或修改文档、表格、应用和网页等文件。具体可用范围、账号资格和地区开放节奏以 Google 页面为准。
💡 AI 助手的交互入口继续从“回答问题”转向直接产出可交付文件，文件版本、权限和人工复核会成为新的产品门槛。
🔗 Google 官方博客；Google Gemini 产品博客
2. Akamai 发布 AI 推理与 Agent 执行服务方向
Akamai 公布 AI Inference Cloud 以及面向 Agent 执行的基础设施方向，强调把推理、工具调用和执行环境放到更靠近用户与数据的位置。公告是产品发布信息，实际区域、性能和商业可用性仍需以服务文档为准。
💡 Agent 基础设施竞争从模型 API 延伸到低延迟推理、沙箱执行和边缘部署，云厂商与 CDN 厂商的边界正在变模糊。
🔗 Akamai 新闻稿；Akamai 产品说明
3. NVIDIA Nemotron Speech 3.5 文档上线，语音 Agent 组件继续工程化
NVIDIA 文档列出 Nemotron Speech 3.5 Transcribe 组件及其部署、推理和使用说明，面向语音转写场景。文档本身证明了组件和接口信息，不能单独推出全面性能结论；实际效果应结合模型卡和独立评测。
💡 语音 Agent 的竞争正在从演示转向可部署组件，延迟、长音频稳定性和流式接口会直接影响真实产品体验。
🔗 NVIDIA 官方文档；NVIDIA AI 模型目录
4. Agentic AI Foundation 接收四个新项目：Skills、Open Responses、OpenEnv 与 OpenSandbox
Linux Foundation 的 Agentic AI Foundation 公布四个新项目，覆盖 Agent Skills、响应协议、环境交互和沙箱执行等层面。项目进入基金会并不等于已经形成统一标准，后续仍要观察实现兼容性和社区采用情况。
💡 Agent 生态开始补“协议、环境和安全边界”这些基础层，真正的开放竞争可能从单个 Agent 框架转向可互操作的底座。
🔗 Linux Foundation 公告；Agentic AI Foundation GitHub 组织
5. 国内气象 AI 模型被用于台风云图解译和强对流预报
Pandaily 报道，中国气象领域正在把 AI 模型用于风云卫星云图解译、台风分析和强对流临近预报。报道属于媒体转述，具体模型名称、评测口径和业务化范围应以主管部门或项目单位的正式材料为准。
💡 国内 AI 产业的可观察落点不只在通用模型，也在卫星、天气和高时效行业数据等高门槛场景。
🔗 Pandaily 报道；中国气象局英文站
6. 钉钉开源 DWS 工作区 CLI，面向 Agent 和多平台开发环境
Pandaily 报道，钉钉开放 DWS 工作区 CLI，覆盖 AI Agent 使用场景以及 HarmonyOS、PC 和 OpenHarmony ARM64 等开发环境。该条以媒体报道为主，开源仓库、版本范围和实际可用能力应以项目公告及仓库内容为准。
💡 国内办公平台开始把 Agent 能力与开发工作区结合，工具是否真正可复用，关键在开放接口、权限模型和本地部署体验。
🔗 Pandaily 报道；钉钉开放平台
7. 研究者提出 Sandman：用睡眠阶段建模提升长程 Agent 记忆管理
arXiv 论文介绍 Sandman 方法，把 Agent 的长期记忆整理、压缩和唤醒类比为睡眠阶段，以降低长期运行中的上下文负担。论文结论仍属于预印本研究，尚未经过同行评审，不能直接视为生产级方案。
💡 长程 Agent 的瓶颈逐渐从“会不会调用工具”转向记忆如何沉淀、遗忘和恢复，值得跟踪可复现实验与真实任务收益。
🔗 arXiv 论文；arXiv cs.AI 最新列表
