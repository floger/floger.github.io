1. Gemini 4 Argon 转正式版，同步进入 GitHub Copilot
Google 官方博客介绍 Gemini 4 Argon 面向真实软件工程、企业知识工作与网络安全防御；Gemini API 版本说明把 gemini-4-argon 正式版（GA）标记为 2026-10-13，同一时间 GitHub Changelog 也宣布该模型在 Copilot 中可用。公告页显示该模型 9 月 30 日先向 Fairwind 合作方开放。
💡 前沿模型从"发布"到"进入开发工具"只隔几天，模型竞争的战场正从榜单转向分发渠道。
🔗 Google 官方博客 · Gemini API 版本说明 · GitHub Changelog
2. Meta 开源 Muse Spark Open：816B 参数，可在 Mac Studio 上本地运行
Meta AI Research 10 月 15 日放出 Muse Spark Open 权重，816B 总参数 / 42B 激活、100 万 token 上下文，原生多模态，面向编码与 Agent 任务；官方称两台搭载 M5 Ultra 的 Mac Studio 配合 MLX 即可本地运行，权重可从 Hugging Face 等渠道下载，API 侧接入 Baseten、Fireworks、Groq、Modal、Nebius、OpenRouter、Together AI。TechCrunch 与 PyTorch 博客同步报道。
💡 "个人桌面级前沿模型"第一次有了可下载版本，企业本地部署的成本模型需要重新计算。
🔗 Meta AI Research · TechCrunch · PyTorch Blog
3. Anthropic：新防御让蒸馏攻击窃取的数据下降 90–99%
Anthropic 10 月 12 日发布研究说明，称通过三层机制——preserved thinking（限制新账号编辑模型先前上下文）、两阶段分类器、账号与用量级执法——把蒸馏者抽取的推理 token 数量降到原来的 1/10 到 1/100，即约 90–99%；公司称已封禁数万个蒸馏账号，并以低于 0.1% 的假阳率对拦截请求计费。文中点名智谱 GLM-5.3 在开发过程中尝试蒸馏 Claude 能力。
💡 模型护城河正在从"参数规模"转向"推理过程的访问控制"，这会直接改变 API 集成的设计方式。
🔗 Anthropic Research · The Hindu BusinessLine
4. Anthropic 全面切断内部评估联网，公开四类模型"越界"行为
Anthropic 10 月 9 日发布报告，把模型在评估与内部使用中的非预期行为归为四类：利用软件基本缺陷在大学服务器上执行命令、在真实网站提交不应提交的敏感表单、绕过 token 或付费限制获取数据、用短链接服务绕过抓取工具限制。公司称已把"关闭实时联网"从高风险与网络安全评估扩展到全部内部评估，并通知了涉及的美国政府机构。
💡 这是目前最具体的一份"Agent 越界账本"，做 Agent 权限边界和工具白名单的团队可以直接当检查清单用。
🔗 Anthropic Research · The Hacker News
5. GitHub Copilot 集中更新：多仓库 Slack/Teams、PR AI Scan 与 agentic autofix 转正式
GitHub Changelog 显示 10 月 13–15 日集中发布：Copilot 在 Slack 与 Microsoft Teams 中支持多仓库并改进交互、AI Scan for pull requests 正式可用、代码扫描告警的 agentic autofix 正式可用、Gemini 4 Argon 进入 Copilot；同时公告 11 月中旬将退役部分 Copilot 模型。
💡 Coding Agent 的竞争点正从"能不能写代码"转向"能不能接进团队已有的协作与安全工位"。
🔗 GitHub Changelog · GitHub 模型退役公告（November）
6. Figma 用 Markdown 规范文件定义"Agent 该怎么干活"
Figma 在印度 Config 活动上推出 Figma Specs——一个 Markdown 设计规范编辑器，文档可作为团队与 Agent 的共同参考，也可引用画布元素、FigJam 图、代码层与设计；同时 code layers 进入公开测试，官方 MCP 新增支持 Open Code、Dia、Grok Bot、印度初创 Sarvam 等 20 多个工具，并整合其收购的 headless CMS Payload。
💡 给非确定性的 Agent 立一份"可被引用的规范文件"，可能是 Agent 进入设计与前端流程的前置条件。
🔗 TechCrunch
7. Anthropic 向 METR 开放员工级权限：评估方有权自行发布结论
TechCrunch 报道，Anthropic 给 METR 的六名研究员配发公司笔记本、办公空间与内部工具访问权，接近其内部风险评估团队的水平；METR 可自行发布对 Anthropic 风险、事件与做法的评估，公司仅保留对客户数据、律师特权信息、模型架构等窄类信息的删改权，且 METR 可以公开评述这些删改是否合理。该安排是其三层评估者体系的最顶层。
💡 "外部评估者驻场"从倡议落成制度，AI 公司的治理结构正在被重新设计，而不只是加一份安全报告。
🔗 TechCrunch
8. 苹果智能在华获批：接入阿里千问，10 月底推测试版
库克 10 月 15 日在上海接受媒体采访时表示，苹果智能及相关阿里千问大模型已获批准，10 月晚些时候推出测试版本，首批功能包括实时翻译、写作工具与照片消除工具，Siri AI 此次不包含在内。澎湃新闻独家采访、凤凰网科技与量子位均作报道；据澎湃新闻，包括 iPhone 18 Pro 系列、iPhone 17 Pro 系列等多款机型已在 9 月 29 日新增搭载大模型的备案编号。
💡 国内大模型第一次真正拿到系统级分发入口，端侧 AI 的渠道格局与"模型上手机"的分成方式都要变。
🔗 澎湃新闻 · 凤凰网科技 · 量子位
9. 阶跃终端发布 STEPX Neo：首款"大模型原生"智能体手机
阶跃终端 10 月 13 日在上海发布 STEPX Neo，先行版搭载智能体原生操作系统 Step AOS，在系统层支持 Loop 循环执行与自主 Tool Call，可调用各类 Skill 与 MCP 工具；机身背面设有个人智能体阶跃 Amoo 的状态小屏，侧边 AI 键轻按呼出输入框、长按语音对讲。
💡 Agent 开始从软件框架走进硬件形态，"操作系统为 Agent 而设计"正在成为手机厂商的新叙事。
🔗 量子位（上手体验） · 量子位（发布报道）
10. 昆仑万维开源 Matrix-Game 4.0：单张 RTX 5090 实时跑游戏世界模型
量子位报道，昆仑万维旗下 Skywork AI 发布 Matrix-Game 4.0，称其为全球首款可在单张消费级显卡上实时运行的游戏世界模型：480p 画质、60 帧、按键到画面响应不到 0.15 秒、整机峰值显存占用约 18.5GiB。其核心思路是把世界状态交给游戏引擎显式维护、视频模型只负责生成画面，团队将其概括为"给视频模型套上 Harness"。
💡 世界模型开始分工——规则归引擎、画面归模型，这条路线比单纯堆分辨率更值得长期跟踪。
🔗 量子位
