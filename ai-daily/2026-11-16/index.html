1. 阿里正式发布 Qwen4-Max：2.4T 稀疏 MoE、原生视觉、1M 上下文，API 同步上线
通义 11 月 16 日发布 Qwen4-Max（此前 11 月 11 日起以 preview 形式在阿里云 Token Plan 提供）：基于全新 Qwen4 架构，2.4T 骨干参数、每 token 激活 71B，另有 328B N-gram Embedding 参数，采用 GDN + Qwen Sparse Attention、门控残差分支等设计，支持原生视觉和 100 万 token 上下文。API 已上线 QwenCloud，定价每百万输入 token 1.5 美元、输出 4.5 美元、隐式缓存 0.075 美元（缓存较 Qwen3.8-Max 降约 70%）；官方 Work360 评测称单任务平均成本从 4.43 美元降到 1.67 美元。Artificial Analysis 第三方测得智能指数 43 分，比 Qwen3.8-Max 高 9 分，落后 Kimi K3.1 Pro 3 分，单任务成本低约 11%。官方称更小的 Qwen4 系列模型将开源，并开源了 Live Delivery 持续交付插件。
值得看：国内旗舰闭源模型这轮打的是“单位任务成本”而不是单一跑分——缓存降 70% 加输出 token 少约 39%（第三方口径），对按任务计费的长 agent 任务影响直接；做 agent 产品的团队可以拿 Qwen-Live-Delivery-Plugin 先试“持续交付”这一交互范式。
Qwen 官方博客（11 月 16 日） · 阿里云 Model Studio 文档 · Artificial Analysis 第三方评测

Jones 为董事长。公司称 2027 财年第三季度财报（11 月 17 日）照常发布。后续报道：华盛顿邮报 11 月 14 日称黄仁勋仍在参与继任搜寻并至少联系过一名潜在人选（正文付费墙未能打开，细节来自与标题一致的公开转述）；金融时报 11 月 15 日称国会正推动更严格的 AI 芯片出口规则（正文同样未能打开，细节以转述为限）；纽约邮报 11 月 14 日报道其在任内的多起职场冲突言论。
值得看：明日（11 月 17 日）就是 NVIDIA 财报电话会——新临时 CEO 的首次公开表态、出口管制问题的官方口径都会在那里出现；关注供应链和算力采购的团队值得等这场电话会再下判断。

3. WSJ：记录显示 Megaspeed 曾安排向中国发送近 120 亿美元英伟达高端芯片
WSJ 11 月 15 日报道（正文付费墙未能打开，以下细节来自公开转述页，与 WSJ 官方账号口径一致）：东南亚的大型数据中心为中国公司提供关键算力，也被指用作涉嫌芯片走私的掩护；该报看到的记录显示，Megaspeed 公司在 2024 年 3 月至 2025 年 6 月间安排向中国境内公司发送近 120 亿美元顶级英伟达芯片。转述页特别指出：记录写的是“安排发送”，未见说明实际交付数量与启运地点；各方对是否违法判断分歧明显。
值得看：这是黄仁勋辞职余波里分量最重的供应链指控，但“安排”不等于“交付”，两个数字被混用的风险很高；引用这条时必须区分“安排发送 120 亿美元”和“实际流入中国 120 亿美元”，等待 WSJ 原文或监管文件再定性。

4. Claude Code 实验功能 Code Mode：让模型写 JavaScript 一次批量调用工具
官方文档确认：Code Mode 是实验性功能、默认关闭（环境变量 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 开启），随 Claude Code 2.1.323（11 月 12 日）加入更新日志。开启后 Claude 不再逐个调用 Bash/Read/Edit 等工具并逐个读结果，而是写一段 JavaScript 在一步里完成多次工具调用（可并行、可串联结果），只把需要的输出交回上下文；目前仅交互式终端可用，不支持 -p、SDK、VS Code 面板与云端，且只走 Anthropic API。
值得看：“工具调用进代码”正成为编码 agent 的主流方向（同一讨论里 Codex 用 v8、OpenCode 用自研解释器）；自建 agent 框架的团队可以直接照抄这个模式——代码聚合调用天然省上下文，代价是要给代码执行加沙箱。
Claude Code 官方文档：Code Mode · Claude Code 更新日志 2.1.323（11 月 12 日）
5. Obsidian 官方推出 Agent Skills：教 agent 操作 vault 与开放格式
Obsidian 团队 11 月 15 日公布官方 Agent Skills 仓库（采集时 52.9k 星、MIT 协议）：用一组 skills 教 agent 通过 Obsidian CLI 和开放格式完整操作 vault，包括 Obsidian Flavored Markdown（wikilink、embed、callout、properties）、Bases、JSON Canvas 等；官方称现有七项 skill。发布者 @kepano 的原帖在 X 上获得约 2000 赞。
值得看：笔记软件把“AI 操作自己的数据”做成了官方 skill 而不是私有插件——本地优先工具的 agent 接入范式可能照此铺开；做个人知识库自动化的用户可以直接 clone 试用，MIT 协议也方便改造成自己的 vault 管理流。
Obsidian Skills 官方仓库
6. 腾讯开源 LoopForge：自托管的编码 agent 交付编排，带人工审批门
腾讯 11 月中旬开源 LoopForge（采集时 2.1k 星，GitHub Trending 当日约 +484）：面向编码 agent 的自托管工作流引擎，用脚本编排 CodeBuddy、Codex、Claude Code 等多个 agent 的交付流程，内置 human-on-the-loop 人工审批门，覆盖代码评审、SDLC 环节，另有面向本地编码助手的 Local workflows；官网 loopforge.cn。
值得看：把“多 agent 协作 + 强制人工审批”做成开箱即用的自托管引擎，是国内团队少见的基础设施向开源；对想在公司内网落地编码 agent 但卡在流程管控和审批留痕的团队，这套“脚本编排 + 审批门”的结构可以直接参考。
LoopForge 仓库
7. NVIDIA 开源 SkillEvaluator：给 agent skill 建多层评测与安全扫描
NVIDIA 开源 SkillEvaluator（采集时 2.1k 星，Apache-2.0）：评测 AI agent skill 质量的多层框架，包括质量门、skill 间语义重叠检测、合成评测数据集生成，以及测量 skill 是否真正改变 agent 行为的活体评测，并带安全扫描组件；官方文档在 docs.nvidia.com/skills/skillevaluator。
值得看：agent skills 生态正在爆发（今天榜上 Obsidian、stitch-skills、ffmpeg-skill 都是这个方向），但“这个 skill 到底有没有用、安不安全”几乎没有标准工具；做 skill/插件市场的团队可以把它的质量门和语义重叠检测当成现成的上架前检查。
SkillEvaluator 仓库
8. Google Chrome 团队 Modern Web Guidance 热度持续：给编码 agent 的现代 Web 最佳实践库
GoogleChrome/modern-web-guidance-src（采集时 7.6k 星，Apache-2.0）近两日在 GitHub Trending 前列：把现代浏览器能力、兼容性建议和推荐写法整理成 skills，供编码 agent 查阅，避免照着旧教程写兼容代码；官方短链 goo.gle/modern-web-guidance。这是既有项目的持续热度，不是本周新发布。
值得看：编程 agent 最大的隐性成本之一是“学了过时写法”——弹窗该用原生 dialog、浮层该看 Popover，这类知识以前靠模型参数记忆，现在被做成可挂载的 skill；给自己的 agent 加一份同类“时代感”知识库，是低成本的准确率提升。
Modern Web Guidance 仓库
9. Ethan Mollick 发布 SatBench：实验室引用的 173 项评测中 63% 已饱和
宾大教授 Ethan Mollick 11 月 15 日发布 SatBench 仓库（CC0-1.0，采集时仅 2 个提交）并称：主要 AI 实验室自 2023 年以来引用的 173 项评测中，63% 已经“实际被打满”，且饱和速度一年比一年快。数据均取自作者原帖，仓库尚在早期，第三方未独立复现。
值得看：和上期 Anthropic 的“单轮安全评测已饱和”互相印证——选模型时盯着官方跑分会越来越没信息量；团队自建评测集、按真实任务分布出题，比追逐榜单更保值，SatBench 的分析方法可以直接借鉴。
SatBench 仓库
10. SemiAnalysis 长文：没有黄仁勋的 NVIDIA 会怎样
SemiAnalysis 11 月 12 日付费通讯《Nvidia and the World Without Jensen》（公开部分已读）：作者认为董事会调查与行为问题是辞职直接原因，但其数据显示超过 1.5GW 受限英伟达芯片最终流入中国，推测辞职与芯片走私压力相关（作者自认的推测）；认为 RASA 类出口管制立法将因“最大辩护者离场”而加速推进，开源生态受冲击；公司结构上黄仁勋有约 60 名直接汇报、未培养出成建制的接班梯队，技术侧继任人选被提及的有 CUDA 创始人 Ian Buck 和 GPU 工程负责人 Jonah Alben，但作者判断无人能复现其对供应链的掌控。
值得看：这是目前对“后黄仁勋时代”最系统的卖方视角：出口管制、开源生态、供应链三条线都可能因人事变动改变节奏；注意文中 1.5GW 与第 3 条的 120 亿美元是两套口径，均属待验证主张。
SemiAnalysis 通讯（11 月 12 日，付费，公开部分已读）
