1. Anthropic 发布 Claude Opus 4.8，继续强化高端模型能力
Anthropic 新闻页显示，公司于 5 月 28 日发布 Claude Opus 4.8，定位为 Opus 级模型升级，强调在多类任务上的表现更强。
💡 Opus 级模型通常代表 Anthropic 的能力上限，它的迭代会直接影响 Claude Code、企业 Agent 和高价值知识工作场景。
🔗 Anthropic
2. Anthropic 完成 650 亿美元 H 轮融资，投后估值 9650 亿美元
Anthropic 官方公告称，公司完成 650 亿美元 Series H 融资，投后估值达 9650 亿美元，资金将用于继续扩展安全、可靠的前沿 AI 系统。
💡 这说明头部基础模型公司的竞争已经进入超大资本开支阶段，算力、人才、企业客户和安全治理都会被继续抬高门槛。
🔗 Anthropic
3. Google 宣布 Gemini App 进入更主动的 Agent 化阶段
Google 官方博客称，Gemini App 正变得更具 Agent 能力，目标是提供更主动、持续的 24/7 帮助，而不只是被动问答。
💡 消费级 AI 助手的下一轮竞争核心是“主动完成任务”，这会改变搜索、提醒、学习、办公和移动入口的产品形态。
🔗 Google Blog
4. Google 在 Gemini API 中推出 Managed Agents
Google 官方开发者文章介绍 Gemini API 的 Managed Agents，帮助开发者更容易构建和托管基于 Gemini 的 Agent 应用。
💡 Agent 能力正在从“开发者自己拼框架”变成云平台内建能力，后续差异会体现在工具、状态、权限和运维管理上。
🔗 Google Blog
5. GitHub Copilot 已支持 Claude Opus 4.8
GitHub Changelog 5 月 28 日宣布，Claude Opus 4.8 已在 GitHub Copilot 中正式可用，扩展了 Copilot 用户可选的前沿模型范围。
💡 编程助手正在从单模型产品变成多模型路由平台，企业会更关注不同模型在成本、速度、代码质量和安全上的组合策略。
