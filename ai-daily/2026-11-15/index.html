AI 日报：2026-11-15

采集于 2026-11-15 · 共 10 条 · 本期事件多发生在美国时间 11 月 13 日（北京时间 13–14 日），World Labs Atlas 为 11 月 12 日补充，日期均按来源标注。已与 11-11、11-13、11-14 期去重。除 OpenAI 官网因反爬返回 403、改用 CNBC 正文交叉核对外，其余均已读取来源正文；产品数据为发布方口径，未独立复现。“值得看”为编辑分析。

1. OpenAI 推出 ChatGPT Wallet：dots 智能体可在逐笔批准后代付
OpenAI 11 月 13 日宣布 ChatGPT Wallet，与 American Express、Mastercard、Visa 合作：用户绑卡一次，每次购买前核对商品、总价和卡片，并用 Face ID 或指纹批准；随后由卡组织生成支付令牌代替真实卡号，智能体和商家都拿不到真实卡号，原卡积分与争议保障保留。首批仅向美国 18 岁以上 ChatGPT Pro 订阅用户、在 dots 中开放；CNBC 同日报道了相同口径。
值得看：这是“agent 付款”第一次由头部模型厂商与三大卡组织一起落地，关键设计是令牌化 + 逐笔生物识别批准；做电商或支付的团队应关注 OpenAI 同时提出的商家侧要求（Web Bot Auth 识别、风控放行）。
OpenAI 官方博客（11 月 13 日） · CNBC 报道
2. Cursor 公布安全事件调查：起点是 Fireworks 泄露的访问密钥
Cursor 11 月 13 日发布调查更新：攻击者拿到 Cursor 发给 Fireworks、由 Fireworks 一方泄露的访问密钥，复制了共享存储桶里主要来自 2025 年、非 Privacy Mode 的 agent 轨迹，其中少量含未脱敏凭据（不到 0.01% 客户的 API 凭据外泄）；再借凭据进入部分 SaaS 工具。10 月 29 日攻击者把篡改版 Claude Code 扩展（2.1.312/2.1.313）放进 Cursor 扩展市场缓存约 11 小时，最多 5000 名用户可能装到。Cursor 已把全部推理迁出 Fireworks、轮换所有内部凭据，称发布签名密钥未泄露。TechCrunch 另报道 Uber 司机驾照信息也在 Fireworks 泄露中被盗。
值得看：一条完整的 AI 供应链攻击链——训练数据共享桶 → agent 轨迹里的明文凭据 → 扩展市场投毒；凡把 agent 日志交给第三方训练或评测的团队，都该先做凭据脱敏与密钥网络范围限制。
Cursor 官方博客（11 月 13 日） · TechCrunch（Uber/Fireworks）
3. DeepSeek 发布“全家桶应用 API”：App 的搜索、文件、读链接能力开放给开发者
DeepSeek API 更新日志 11 月 13 日条目：在原有 API 中开启参数即可获得联网搜索（deepseek_web_search，思考模式下可多步推理中自主搜索）、文件输入（PDF、Office、图片解析后拼入上下文）、阅读链接（deepseek_read_url）和模型安全校验，工具调用与上下文拼接由服务端完成；Search、Fetch、OCR、ASR、TTS 也可作为独立接口调用。
值得看：国内开发者不必再自己拼“搜索 + 抓取 + 解析”链路；对外提供服务时官方要求开启安全参数并自行承担内容审核、大模型登记、AI 标识义务，上线前要把合规成本算进去。
DeepSeek API 官方更新日志（11 月 13 日）
4. Google Antigravity 推出 Dynamic Workflows：让 agent 写 Python 脚本编排子 agent
Antigravity v2.32.0（11 月 13 日）加入 Dynamic Workflows：使用 /run-workflow 后，agent 编写并运行一段 Python 脚本，用 parallel() 并行、pipeline() 顺序调度子 agent，每个子 agent 在独立对话中工作并按 JSON Schema 返回结构化结果，脚本可保存复用。官方文档称面向 Google AI Pro 与 Ultra 用户，在 Antigravity 应用和 CLI 中可用，自带 Python 运行时。
值得看：多 agent 编排从“提示词里描述流程”变成“可审阅、可复用的代码”，主对话上下文不再被子任务日志淹没；自建 agent 工作流的团队可直接借鉴“脚本编排 + Schema 返回”的结构。
Antigravity 官方文档 · Antigravity 更新日志 v2.32.0
5. Sierra 发布个人 agent 协议 Poppy v1.0：Shopify 全量开启
Sierra 11 月 13 日发布 Personal Agent Protocol（Poppy）v1.0：协议规定个人 agent 如何发现企业能提供的服务、表明身份，并通过 OAuth 由用户控制权限，大量复用 MCP、OpenAPI、UCP 等现有标准。Shopify 每家店铺自动发布 Poppy 文件；Meta 的 Muse 访问网站时会优先查找 Poppy；新增 60 家设计伙伴，总数超过 100 家，Mercury、Synchrony、土耳其航空已上线。
值得看：与第 1 条的“agent 付款”是同一趋势的另一半——agent 如何进门、亮身份、获授权；做 C 端服务的企业可以用官方实现套件和校验器评估接入成本。
Sierra 官方博客（11 月 13 日）
6. LangChain 完成 3 亿美元 C 轮，估值 30 亿美元
LangChain 11 月 13 日宣布 C 轮融资 3 亿美元、估值 30 亿美元，由 CapitalG 领投，GIC、DFJ Growth 新进，IVP、Sapphire Ventures 等跟投。官方称超过 7000 家组织使用 LangSmith，产品分为 Agent Runtime、Agent Improvement、Agent Governance 三块，并将在 11 月 20 日发布新功能。
值得看：资本押注“模型无关、企业自控”的 agent 平台；正在选型 agent 观测/评测/网关的团队，11 月 20 日的发布值得等一等再定。
LangChain 官方博客（11 月 13 日）
7. Anthropic 发布安全评测方法建议：单轮评测已饱和，配置差异可达 34 个百分点
Anthropic 11 月 13 日发文分享构建 AI 安全评测的建议：近期各模型在 API 上单轮安全评测的无害回应率都在 94%–98%，已饱和，主要用于回归检查；同一 Claude Fable 5.1 在 API 与 claude.ai（带系统提示）两种配置下，多轮安全评测的恰当回应率最多相差 34 个百分点；自伤相关评测加入新系统提示后，claude.ai 为 94%、API 为 60%。文章建议报告配置、做统计显著性检验、在无网络沙盒中运行评测。
值得看：说明“模型安全分数”高度依赖系统提示与部署配置；直接调 API 的产品不能照搬官方 App 的安全表现，需要自己补系统提示和评测。
Anthropic 官方文章（11 月 13 日）
8. Fortune：OpenAI 解散独立机器人团队，研究员并入主研究团队
Fortune 11 月 13 日独家报道，OpenAI 向其确认重组：机器人研究人员并入首席研究官 Mark Chen 领导的主研究团队，应用机器人和硬件团队并入总裁 Greg Brockman 负责的 Applied 部门。公司发言人称机器人仍是长期愿景核心，此举是为加快进展而非退出，理由是 GPT-6 Astra 等通用模型已能直接控制机器人完成部分任务。
值得看：头部实验室押注“通用模型即机器人大脑”，对靠专用机器人模型融资的初创公司是路线挑战；但这是媒体报道 + 公司口径，具体效果尚无公开数据。
Fortune 独家报道（11 月 13 日）
9. World Labs 向所有人开放 Atlas 世界模型及开发者 API
补充 11 月 12 日进展：World Labs 发布 Atlas 工具链与开发者 API，包括从照片或生成图重建场景并渲染镜头路径的 Viewfinder、可控搭建场景的 Chisel、把 splat 转为网格的 Splats to Mesh 和 Relight，并支持接入 Blender 等现有工具，面向影视、建筑设计和机器人仿真场景。
值得看：世界模型从演示走向可调用的 API，3D 内容和机器人仿真团队可以把“照片 → 可编辑 3D 场景”接进现有管线；定价和第三方评测仍不透明，先小规模试用。
World Labs Atlas 官方页面 · World Labs 博客（11 月 12 日条目）
10. Google 把 Google Wallet 接入 Gemini：只读的个人财务分析
Google 11 月 13 日宣布，美国所有 Gemini 应用用户可在 Personal Intelligence 中连接 Google Wallet，并可通过 Plaid 关联银行和信用卡账户，用于分析消费、找出订阅与涨价、制定预算；Google 强调连接为只读，Gemini 不能转账、管理或投资资金。同时推出 Memory Summary，可查看和编辑 Gemini 记住的偏好。
值得看：与 OpenAI 同日的 Wallet 形成对照——一个让 agent 花钱，一个只让 agent 看账；评估个人财务类 AI 功能时，“读/写权限边界”是首要设计问题。
Google 官方博客（11 月 13 日）
