1. OpenAI 与德国电信合作，推动电信运营商 AI 化
OpenAI 表示，德国电信正在使用其模型改造客服、员工工作流、网络运营等环节，并探索语音服务等应用。该信息来自 OpenAI 官方发布。
💡 AI 竞争正从模型能力扩展到传统行业的流程重构，电信运营商是观察 Agent 落地的典型样本。
🔗 OpenAI 官方
2. 视频生成公司 PixVerse 融资 4.39 亿美元，估值超过 20 亿美元
TechCrunch 报道，视频生成初创公司 PixVerse 完成 4.39 亿美元融资，估值升至 20 亿美元以上；公司计划用资金扩展其“世界模型”产品并拓展全球客户。
💡 资本开始押注的不只是视频特效，而是能理解和生成动态世界的模型路线。
🔗 TechCrunch
3. Hermes Agent 开发商 Nous Research 据报寻求新一轮融资
TechCrunch 报道，Nous Research 正洽谈至少 7500 万美元的新融资，潜在估值约 15 亿美元，Robot Ventures 领投，USV 等机构参与。
💡 开源模型与 Agent 基础设施公司开始获得独立于模型巨头的高额估值，生态层竞争正在升温。
🔗 TechCrunch
4. Google 扩展 Gemini API Managed Agents，加入后台任务与远程 MCP
Google 官方宣布，Gemini API 的 Managed Agents 新增后台任务、远程 MCP 等能力，目标是帮助开发者构建更可靠、可投入生产的 Agent。
💡 Agent 平台的竞争焦点从“能不能调用工具”转向任务调度、连接外部系统和稳定运行。
🔗 Google Blog
5. Hugging Face 发布 PyTorch 注意力机制性能分析指南
Hugging Face 博客发布 Profiling in PyTorch 第三部分，聚焦注意力机制的性能剖析，帮助开发者定位 Transformer 推理和训练中的计算瓶颈。
💡 模型继续变大之后，真正决定成本的往往不是参数量，而是对热点算子和内存访问的精细优化。
🔗 Hugging Face Blog
6. Hugging Face 与 NVIDIA 发布面向 Agent 的开放数据方案
Hugging Face 发布“Data for Agents”，介绍面向 Agent 训练和评测的开放数据策略，强调数据在 Agent 系统能力建设中的基础作用。
💡 Agent 的下一轮差异化可能来自高质量任务轨迹和工具使用数据，而不只是更大的通用语料。
🔗 Hugging Face Blog
7. Hugging Face 发布原生高速 vLLM Transformers 建模后端
Hugging Face 介绍新的 vLLM Transformers 建模后端，目标是在保持 Transformers 模型兼容性的同时提供更接近原生推理引擎的速度。
💡 开源生态正在补齐“模型发布—推理部署”之间的最后一公里，开发者迁移模型的成本可能进一步下降。
🔗 Hugging Face Blog
8. 量子位：Agent 专用搜索登顶 Product Hunt
量子位报道，一款面向 Agent 的专用搜索产品登上 Product Hunt 热门榜，主打更少 Token 消耗和更准确的检索，报道指出其背后为中国团队。
💡 Agent 搜索正在从“给人看的网页搜索”分化，检索结果的结构化和 Token 效率会成为新指标。

🔗 量子位
