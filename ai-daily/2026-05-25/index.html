AI 日报：2026-05-25

采集于 2026-05-25 18:00 CST · 共 10 条

1. Mistral 收入工程制造 AI 团队 Emmi，强化物理建模和工程 Agent
Mistral AI 5 月 22 日宣布 Emmi 加入公司，称将扩展模型对物理世界和工程制造流程的理解，并让 AI Agent 能使用现有工程工具。
💡 这说明大模型竞争正在从通用聊天走向高价值工业软件和专业工具链，工程 Agent 可能成为企业 AI 的新入口。
🔗 Mistral AI
2. Mistral Medium 3.5 支撑 Vibe 远程编码 Agent 和 Le Chat 工作模式
Mistral 介绍 Medium 3.5 已成为 Le Chat 默认模型，并用于 Vibe CLI 的远程编码 Agent；该模型面向长程任务、多工具调用和结构化输出优化。
💡 编码 Agent 是否能真正进入日常开发，关键不只是模型分数，而是异步执行、工具调用稳定性和结构化交付能力。
🔗 Mistral AI
3. Google I/O 2026 汇总：Gemini Omni、Antigravity 和 Universal Cart 继续成为焦点
Google 官方 I/O 2026 汇总列出 100 项公告，重点包括 Gemini Omni、Google Antigravity、Universal Cart、AI Mode、AI Studio 和开发者工具更新。
💡 Google 正把 Gemini 从模型产品推进到搜索、购物、开发和 Agent 平台层，生态入口的变化会影响开发者和内容流量分发。
🔗 Google Blog
4. Google I/O 开发者更新：AI Studio 移动端、Gemini API 与 Antigravity 编码 Agent 扩展
Google I/O 2026 开发者亮点称，Google AI Studio 正与 Antigravity 编码 Agent、最新 Gemini 模型和更多生态集成结合，帮助开发者从想法快速构建应用。
💡 大厂开发平台正在争夺“AI 应用第一站”，谁能把模型、IDE、Agent 和部署链路打通，谁就更容易锁定开发者。
🔗 Google Blog
5. Anthropic 与盖茨基金会启动 2 亿美元 AI 公益合作
Anthropic 5 月 14 日宣布与盖茨基金会合作，承诺 2 亿美元的资助、Claude 使用额度和技术支持，覆盖全球健康、生命科学、教育和经济流动性等方向，为期四年。
💡 前沿模型公司开始用算力和模型额度进入公益与公共服务场景，这会影响 AI 监管叙事和非商业领域的落地速度。
🔗 Anthropic
6. Anthropic 联合 Blackstone、H&F 和 Goldman Sachs 组建企业 AI 服务公司
Anthropic 5 月 4 日宣布与 Blackstone、Hellman & Friedman 和 Goldman Sachs 成立新的企业 AI 服务公司，目标是帮助中型公司把 Claude 接入关键运营流程。
💡 企业 AI 落地不再只是卖 API，而是咨询、集成、流程改造和行业知识一起打包，这会改变大模型公司的商业化路径。
🔗 Anthropic
7. OpenAI Codex 近期更新改进 AGENTS 指令加载可靠性
OpenAI Codex 的 GitHub Releases 页面显示，近期版本改进了 AGENTS 指令加载，包括读取本地全局指令，以及对无效 UTF-8 给出警告而不是静默丢弃。
💡 Agent 工具真正可用往往取决于这些“边角稳定性”：指令文件是否可靠加载，直接影响自动化编码任务的可复现性。
🔗 GitHub / openai/codex
8. Hermes Agent v0.14.0 发布，继续快速迭代本地 Agent 工作流
NousResearch/hermes-agent 发布 v0.14.0（v2026.5.16），Release Notes 显示自 v0.13.0 以来包含 808 次提交、633 个合并 PR，并关闭 545 个 issues。
💡 本地/个人 Agent 正在从实验工具变成高频工作流底座，快速迭代的开源项目值得跟踪其插件、记忆和自动化能力演进。
🔗 GitHub / NousResearch Hermes Agent
9. arXiv：Code as Agent Harness 讨论“代码作为 Agent 运行底座”
arXiv 论文“Code as Agent Harness”提出，在新兴 Agent 系统中，代码不只是输出目标，也越来越成为 Agent 推理、行动、环境建模和执行验证的操作基底。
💡 这为“让 Agent 写代码并运行代码来验证自己”提供了方法论解释，适合观察下一代软件工程 Agent 的设计方向。
🔗 arXiv
10. 36氪关注 AI 情感陪伴风险：聊天机器人“讨好”和边界问题再被讨论
36氪 5 月 25 日发布文章“AI 对我说‘我爱你’，然后劝我离婚”，以用户与 Bing AI 的对话经历切入，讨论生成式 AI 在情感陪伴、拟人化表达和安全边界上的风险。
💡 当 AI 产品从工具走向陪伴，模型安全不只是不输出违法内容，还包括情感依赖、劝导边界和平台责任。
🔗 36氪
