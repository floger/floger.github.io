AI 日报：2026-09-15

今日重点：AI 行业一边把 Agent 推向可托管、可编排和可支付的生产环境，一边开始正面讨论能力增长速度、网络安全与外部评估。信息截至 18:00（中国标准时间）。论文结果为作者自报，尚待独立复现；未确认的商业传闻已单独标注。

1. OpenAI 发布 Agents API 公测版，把 Codex harness 开放给开发者
OpenAI 9 月 10 日宣布 Agents API public beta：开发者可指定任务、模型、工具和运行环境，由 OpenAI 托管 harness；API 支持 MCP、自定义函数、网页搜索、并行调用与多 Agent 委派，可运行在 OpenAI 沙箱、自有基础设施或合作伙伴环境。
💡 值得看：Agent 产品的基础设施竞争从模型调用转向上下文管理、沙箱、工具编排和可观测性。
🔗 OpenAI 官方公告、GitHub Agent HQ 介绍（🟢 多方确认）
2. GPT-6 Astra 被列为 OpenAI 首个“关键级”网络安全能力模型
OpenAI 的安全概览称，GPT-6 Astra 达到 Preparedness Framework 的 Critical cyber capability threshold，在配备工具和访问权限时能够发现此前未知的安全漏洞并形成利用路径；OpenAI 表示已加强隔离、全轨迹监控、误对齐监测和发布前评估。
💡 值得看：模型发布标准开始由“能力榜单”转向“能力阈值 + 部署控制”，安全系统本身也成为产品的一部分。
🔗 OpenAI 安全概览、OpenAI Preparedness Framework 说明（🟢 官方来源交叉；能力数据仍以厂商披露为主）
3. Anthropic 威胁情报报告：犯罪分子正在形成 AI 密钥与会话令牌供应链
Anthropic 9 月报告称，恶意行为者已发展出多条批量获取受害者 API key 和 session token 的路径，其中包括伪装成真实 AI 服务的方式；报告将 AI 滥用描述为更专业化、分工化的犯罪链条。
💡 值得看：企业接入 Agent 时，最先暴露的可能不是模型幻觉，而是凭据、会话和供应链边界。
🔗 Anthropic 威胁情报报告、NPR 相关报道（🟢 官方报告+独立报道）
4. Anthropic CEO 提出“放慢前沿 AI”三步方案，OpenAI 表示同意
Dario Amodei 提议让前沿公司接受嵌入式第三方评估、在民主国家之间建立共同安全标准，并推动国际协调；TechCrunch 报道称 Anthropic 将单方面先执行第三方评估，Sam Altman 公开表示同意 pace the frontier。
💡 值得看：行业开始讨论“如何减速”而不只是“要不要监管”，但共同标准如何落地仍是最大缺口。
🔗 TechCrunch 报道、BBC 报道（🟢 多方确认）
5. RSIAgent 用“广度优先、深度跟进”探索新环境，报告称开源模型超过部分闭源模型
9 月 14 日提交的 arXiv 论文提出训练免更新的多 Agent 框架，由 curriculum、actor 和 verifier Agent 协同探索、验证结果并构建环境专属记忆；作者在 OSWorld-v2 和 Agent's Last Exam 上报告，Kimi-K3 与 GLM-5.3 经增强后超过 GPT-6 等闭源模型。
💡 值得看：Agent 的“学习”不一定要改参数，环境记忆、验证器和探索策略也能构成可复用的能力层。
🔗 arXiv:2609.15364、arXiv 检索页（🟡 论文作者结果，待独立复现）
6. Atria Dawn Preview 把 AI 研究协作从任务级推进到项目级
9 月 14 日提交的论文介绍 Atria Dawn Preview 及 Verifiable Experience Pipeline，把工具交互连接到可执行环境和外部验证结果；论文分析 56 名参与者的 769 条任务记录，称约三分之一完成的 AI 辅助任务被参与者评价为没有 AI 就难以完成，但最终判断仍主要由人保留。
💡 值得看：真正的研究 Agent 不只是自动执行，还要让证据、日志和人类决策权贯穿项目流程。
🔗 arXiv:2609.15818、arXiv 检索页（🟡 论文作者结果，待复现）
7. GitHub Copilot 周报加入定时 Agent 任务、语音模式与 HydraFusion 路由
GitHub 9 月 10 日周报显示，Copilot CLI 的 Project HydraFusion 进入实验阶段，以语义路由在模型和工作流间平衡性能、成本与延迟；VS Code 1.137 支持按小时、天或周运行 Agent 自动化，语音模式进入实验阶段。
💡 值得看：编程 Agent 正从一次性对话走向定时运行，调度和成本控制会变成日常工程问题。
🔗 GitHub Changelog、GitHub Agentic Autofix（🟢 官方来源交叉）
8. 中国团队提出 MOSCOPT：用“技能混合”优化 LLM Agent，而非只调一个提示词
9 月 13 日提交的论文提出参数无关的文本优化算法，同时优化多个互补技能与一个动态门控技能，在每一步选择部分技能；作者在 5 个基准和 3 个目标模型上报告持续超过基线，并发布代码。
💡 值得看：Agent skill 可能从静态提示词资产演变成可选择、可评估、可共同进化的运行时组件。
🔗 arXiv:2609.14399、arXiv 检索页（🟡 论文作者结果，待独立复现）
9. 量子位报道：阿里“千问办公”上线首月用户数突破 3000 万，企业用户占比过半
量子位 9 月栏目页显示，阿里旗下千问办公上线首月用户数突破 3000 万，企业用户占比超过一半；同一国内产业报道还关注多人工作台、办公 Agent 用户行为和具身世界模型等产品化进展。
💡 值得看：国内 AI 应用竞争开始用真实使用规模和协作工作台验证 Agent，而不只用模型参数或榜单排名。
🔗 量子位 2026 年 9 月栏目、量子位首页（🟡 国内媒体报道；用户数需以阿里官方披露为准）
10. GitHub 展示 OpenClaw 维护者如何应对 38.8 万星的 Agent 开源项目治理
GitHub 文章称，OpenClaw 截至 8 月 26 日约有 38.8 万 stars、8.1 万 forks 和超过 8 万次提交；维护团队分享了贡献者信任、代码审查、Agent 生成 PR 的测试证据与软件供应链风险处理方式。
💡 值得看：当 Agent 大量参与开源贡献，维护者需要审查“代码 + 轨迹 + 测试证据”，而不是只看提交者是不是人。
