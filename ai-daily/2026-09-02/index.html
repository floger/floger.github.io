AI 日报：2026-09-02

今日重点：AI Agent 正在把“选择看什么、调用什么工具、何时停止”做成运行时能力；与此同时，前沿模型的网络安全边界、企业工作流治理和多 Agent 记忆成为焦点。信息截至 18:00（中国标准时间）。

1. Gemini 推出 Agentic Video Understanding，视频分析最多少用 88% token
Google 于 9 月 1 日宣布，Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite 可在视频分析中动态选择要查看的片段、帧率、音频和字幕，而不是固定按帧采样。Google 称在标准视频基准上 token 消耗最多降低 88%、分析成本最多降低 66%、准确率最多提升 7%；目前通过 Gemini API、AI Studio 和 Gemini Enterprise Agent Platform 提供。
💡 值得看：长视频 Agent 的关键优化不再是压缩输入，而是让模型主动决定哪些证据值得读取。
🔗 Google 官方博客；Android Authority（🟢 官方公告 + 独立媒体交叉）
2. OpenAI 将 Astra 列为首个“关键级”网络安全能力模型
OpenAI 表示，Astra 已达到其 Preparedness Framework 的 Critical 网络安全阈值：在具备工具和访问权限时，模型能够在没有人逐步指导的情况下发现并利用多类系统漏洞。公司称 Astra 在内部 ExploitBench 上取得满分，并在评测中发现并利用了两个零日漏洞，相关漏洞正在向维护者披露；模型计划“很快”发布，先进网络安全能力将受限开放。
💡 值得看：模型发布门槛已从“能力更强”转向“监控、隔离和滥用控制是否足以承受能力跃迁”。
🔗 OpenAI 官方说明；ByteIota 独立分析（🟡 官方自报数据；缺少第三方复测）
3. OpenAI 把企业 AI 竞争总结为“工作流执行能力”
OpenAI 9 月 1 日介绍 Basis、Clay 和 Exa Labs 的企业实践：把一次性经验固化为可复用 skill，为 Agent 提供持续更新的上下文，并让 Agent 在权限、测试和人工复核下完成从信号发现到代码提交的流程。OpenAI 的 Enterprise Signals 称，AI 使用量最高的前 10% 企业，每个活跃用户的输出 token 数是典型企业的 8.3 倍，高于 1 月的 2.6 倍。
💡 值得看：企业落地的分水岭不是接入聊天机器人，而是能否把权限、证据、KPI 和复核点嵌进可重复流程。
🔗 OpenAI 官方案例；RingCentral 案例（🟡 同一官方体系的不同案例；数据仍主要来自厂商披露）
4. Anthropic 的自动化研究员在 10 类对齐失败上取得改进
Anthropic 与合作研究者发布自动化对齐研究：让 Agent 反复提出训练方法、准备数据、训练并测试模型，针对欺骗、谄媚、越狱等 10 类对齐失败进行优化。报告称最佳方法在不同任务上关闭了 26%—96% 的安全差距，部分方法在留出基准、多轮 Petri 审计以及规模最多 4.7 倍的模型上保持效果；研究代码和完整论文已公开。
💡 值得看：安全工作也开始采用“实验—评测—迭代”的 Agent 循环，但基准分数不能等同于真实世界安全。
🔗 Anthropic 研究；arXiv 论文（🟢 官方研究 + 论文原文）
5. Claude Fable 5.1 与 Mythos 5.1 上线，缓存读取价格降低 75%
VentureBeat 报道，Anthropic 于 9 月 1 日推出 Claude Fable 5.1 和受限访问的 Mythos 5.1；Fable 5.1 的缓存命中输入价格降至每百万 token 0.25 美元，较 Fable 5 的 1 美元下降 75%。报道同时称，Mythos 面向网络安全和生命科学等受信任访问场景；模型能力、定价和可用范围应以 Anthropic 官方产品页最终说明为准。
💡 值得看：Agent 工作负载的成本优化越来越依赖缓存、持久上下文和路由，而不只是单次 token 单价。
🔗 VentureBeat；Anthropic Newsroom（🟡 媒体报道 + 官方新闻入口；具体型号资料待官方页面补全）
6. Perplexity 推出云端与本地模型动态接力的混合 Agent
VentureBeat 报道，Perplexity 面向企业及 Pro、Max 用户推出混合 AI 能力：任务可从云端开始，将涉及敏感文件的部分动态交给用户 Apple 芯片设备上的本地模型处理，并保持任务上下文。报道说该功能默认让文件和工作留在本地，向云端发送单个步骤前需要用户许可；目前信息主要来自产品与媒体披露。
💡 值得看：隐私 Agent 的竞争点从“本地模型能不能跑”转向“云本地切换时能否不丢上下文”。
🔗 VentureBeat AI；Perplexity 产品页（🟡 媒体报道 + 产品入口；实际地区和套餐限制需实测）
7. GitHub Agent Plugins 1.0 将 skills 与 MCP server 打包为可移植插件
GitHub 宣布 Agent Plugins 1.0 在 VS Code、Copilot CLI 和 Copilot app 等客户端可用。插件可同时携带 skills、MCP server 配置及相关 Agent 扩展，兼容客户端可复用同一份插件；企业管理员还可以通过已有设置控制允许的插件、市场和 MCP server，且 Agent Finder 不会自动安装发现的能力。
💡 值得看：Agent 工具链开始出现类似软件包管理的分发、权限和治理层，插件审计会成为部署前置步骤。
🔗 GitHub Changelog；GitHub Agent Finder（🟢 官方两篇公告交叉）
8. 新论文提出用门控记忆降低多 Agent 协作的上下文成本
arXiv 论文《Learning What to Retain》提出 Gated-Memory Routing：通过角色分配、检索门、写入门和自适应停止控制器，只保留对下一步有用且不重复的推理状态，而不是把完整历史交给每个 Agent。论文目标是同时减少上下文长度、无效协作和过早或过晚停止的问题，当前仍是预印本。
💡 值得看：多 Agent 系统的瓶颈正从“能否协作”转向“共享什么记忆、何时停止、如何为成本负责”。
🔗 arXiv 原文；AI Agent Papers 精选索引（🟡 论文原文 + 独立领域索引；待同行评议）
9. 北理工等团队发布 VGEBench，测试 Agent 无说明书操作家用设备
arXiv 论文《Towards Generalizable Visually Grounded Exploration of Household Devices》提出 VGEBench，让视觉语言模型在没有说明书和标注轨迹的情况下，通过观察、交互和反馈探索 968 台、26 类家用设备。论文关注 Agent 能否把抽象常识落到具体按钮、旋钮和物理反馈上，而不是只做静态识别。
💡 值得看：具身智能的难点不是“看懂物体”，而是对陌生设备形成可验证的行动假设并在失败后修正。
🔗 arXiv 原文；arXiv cs.AI 当日列表（🟡 论文原文 + 分类索引；预印本待复现）
10. 国内 AI 产业继续押注 Agent 化量化研究与国产算力
量子位近期报道了量化研究 Agent AQuA、范式与华为算力合作，以及灵犀智涌将机器人用于工业具身智能等动态；这些报道显示国内产业关注点正从通用模型发布扩展到金融研究、国产算力适配和工业落地。相关项目的商业数据与性能结论主要来自媒体和企业披露，不能直接视为独立测评。
💡 值得看：国内 AI 产业化的竞争越来越体现为场景数据、算力底座和可交付系统的组合，而非单一榜单成绩。
