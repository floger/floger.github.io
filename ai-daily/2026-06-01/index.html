1. OpenAI Codex 更新 Windows 端 computer use 与移动访问能力
OpenAI Developers 的 Codex changelog 显示，Codex 最新更新包含“Computer use and mobile access on Windows”，并继续发布 Codex CLI 0.135.0、0.134.0 等版本。

2. GitHub Copilot 代码审查从 6 月 1 日起消耗 Actions minutes
GitHub Docs 明确写明，自 2026 年 6 月 1 日起，Copilot code review runs 将消耗 GitHub Actions minutes；此前 GitHub Changelog 也预告了这一变化。
💡 AI 代码审查开始进入 CI 成本账户，团队需要把 Agent 工具的调用频率、仓库类型和预算治理一起纳入工程管理。
🔗 GitHub Docs
