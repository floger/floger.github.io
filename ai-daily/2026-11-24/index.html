1. 智谱发布 GLM-5.4：28 层循环两遍，权重开放仍是计划
Z.ai 11 月 23 日原文介绍，GLM-5.4 在 GLM-5 基座上把 28 层共享权重循环执行两遍，配合逐 token 门控、跨轮 KV 共享与独立滑动窗口，以及稀疏注意力索引复用。团队明确承认模型可能陷入过长的思考循环。公告列出 Coding Plan、ZCode 和聊天入口，通用 API 标为“即将推出”，权重需完成安全加固后再开放；不能写成今日已开源或所有 API 账号均可调用。
值得看：循环深度把部分计算从显式推理 token 移到网络内部，选型要同时测墙钟耗时、实际费用与任务正确率。先对比长任务、重复思考和超时退出，别把参数不增长理解成推理计算不增长；Coding Plan 是付费订阅。
Z.ai 官方架构、入口与开放计划（11 月 23 日） · 该官方页面实际加载的文章正文资源
2. Claude Ship 开放 beta：修复 Agent 不负责批准，审批策略先只观察
Anthropic 11 月 23 日推出 Claude Ship，把已正式可用的 Code Review 与 beta 阶段的 PR Steward、Claude Approvals 组合起来。PR Steward 处理 CI 失败、冲突和反馈，但设计上不批准或合并 PR；审批由仓库内的策略文件约束，官方建议先以 observe-only 模式试运行。服务面向 GitHub 仓库的 Team、Enterprise 计划，按 token 计费；不支持启用 ZDR、HIPAA 配置或客户管理加密密钥的组织。
值得看：可吸收的是“写代码、修复、批准”职责分离，而非直接让 Agent 自己写完自己放行。先在单仓库验证分支保护、停止指令、预算上限和高风险改动转人工；observe 模式里的分类器与评审也可能计费，不等于免费试跑。
Anthropic 官方能力、权限与计费边界（11 月 23 日）
3. OpenAI 与 Cisco 开源 Shirudo：临时运行时护盾，不是永久补丁替代品
双方 11 月 23 日介绍 Shirudo，以签名护盾和运行时验证，在滚动修补期间保护仍在运行的 Linux 系统。Cisco 的受控演示使用 Codex 生成 Java 字节码校验，附加到 Elasticsearch 9.5.5 的运行进程，阻断 Java4Shell 测试攻击而不重启；该示例不能简单写成“仅靠 eBPF 修好了 Java”。项目同时利用 eBPF、签名校验和 TPM 记录，最终部署仍由安全团队控制。
值得看：对无法立即重启的内网服务，重点是补丁空窗期如何建立可验证的临时防线。先读代码与硬件前提，在隔离环境验证正常流量、回滚和正式补丁后的撤除；开源不代表可以跳过内核权限、安全审计和变更审批。
OpenAI 官方发布（11 月 23 日） · Cisco Isovalent 技术正文与受控测试（同日、共同开发方） · 项目原始仓库
4. Amazon 签约购买 Decart 优化技术：尚待交割，未披露的金额不补写
Amazon 11 月 23 日宣布签署协议，购买 Decart Optimization Stack 的专有技术，并计划引入 Decart 联合创始人和研究工程团队。双方自 2025 年起合作优化 Trainium，公告将交易目标指向软硬件协同、模型训练与推理效率。完成交易仍取决于包括监管许可在内的惯常交割条件，不能写成已经完成对整个公司的收购，也不能把预期成本改善当作已实现收益。
值得看：AI 基础设施竞争不仅是买芯片，也是在补编译、内核和模型适配能力。后续应追踪具体模型、硬件与端到端成本的实测，不拿厂商愿景代替自己的吞吐、延迟和迁移成本验收。
Amazon 官方协议范围、合作背景与交割条件（11 月 23 日）
5. DeepMind 用 Gemini 团队与 Lean 优化量子算法：资源估算下降，不是硬件已实现突破
Google DeepMind 11 月 23 日公布，以独立 Gemini 4 Agent 团队提出算法改进，经 Lean 检查后再进入共享笔记，并每四小时交流。作者报告某聚变模拟电路的综合计算成本降低 11.8 倍，所需纠错逻辑量子位从 5,650 降至 4,338；同时开放 Lean 库、问题定义和验证方案。文章明确这些算法仍可能超出首批纠错量子计算机的资源能力，本期未运行证明或电路。
值得看：有价值的是“候选必须先通过可执行验证，再分享给其他 Agent”的协作门禁。用于软件工程时，可把类型检查、测试和不变量验证放在共享知识之前，避免并行 Agent 把未经确认的想法互相强化。
Google DeepMind 原始研究说明、指标与资源限制（11 月 23 日）
6. AISI：同一监控器漏报率从 0.2% 到 23%，差别可能来自攻击样本怎么造
英国 AISI 11 月 23 日研究比较基本提示、优化提示、强化学习和转写攻击记录等生成策略。在一个已退役的 OpenAI 监控提示、GPT-5.4 监控器与 Qwen 3.8 27B 被监控 Agent 的案例中，成功有害攻击的漏报率随生成策略从 0.2% 变到 23%。作者强调这只是一个监控器与一个 Agent 的案例，合成攻击能否代表真实部署仍未解决，不能外推为所有现役监控系统的漏报率。
值得看：买安全能力或验收自动审批时，不只问“拦住了百分之几”，还要问样本生成方法、优化预算及分母。保留真实失败回归，并把最小权限、沙箱与高风险人工审批作为独立防线，别让单一分数成为放权理由。
AISI 原始方法、结果与适用范围（11 月 23 日）
7. Anthropic 访谈 58 家企业：少见自动化直接裁员，不代表就业没有受到影响
Anthropic 11 月 23 日发布美国 58 家企业、66 次访谈的定性研究，样本全部为其企业客户，并非随机或代表性抽样。受访者描述多数 AI 用例的价值来自增加产出，约三分之二受访企业报告因 AI 减少招聘，九家描述减少外包。作者同时观察到评审、部署、组织协调和维护瓶颈；这些是客户自述与研究编码，不是证明 AI 对全美就业因果效应的统计实验。
值得看：把“原型做得快”与“企业交付变快”分开。团队可先盘点最慢的交接、谁维护非开发人员写的应用、谁验收数据权限；用端到端周期衡量收益，不用生成代码行数或少裁员就推断已经转型成功。
Anthropic 原始访谈报告、样本与局限（11 月 23 日）
8. Google 搜索接入 Wallet 个人上下文：只读，不会替用户转账或投资
Google 11 月 23 日宣布，AI Mode 的 Personal Intelligence 开始逐步支持用户自愿连接 Google Wallet，Drive 和 Gemini 应用的连接将在随后几周到来。公告明确 Wallet 连接只允许读取账号信息，不能移动、管理或投资资金；用户可随时关闭连接。不能把后续几周的计划写成全部立即上线，也不能把个性化消费分析写成已经开放自动付款。
值得看：搜索产品正在从公共网页走向私人数据上下文，验收应单独检查连接范围、撤销是否生效和答案用了哪些数据。给用户解释“会读什么、不能做什么”，比笼统宣称有个懂你的 Agent 更有用。
Google 官方功能、分批上线与只读限制（11 月 23 日）
9. Figma Agent 在 FigJam、Slides 正式可用：先整理证据，再生成方案和演示稿
Figma 11 月 23 日宣布，其 Agent 在 FigJam 和 Figma Slides 的所有付费计划上正式可用，两者支持部分连接器与附件。FigJam 可把便签、评论和外部材料整理为保留原始讨论上下文的 Spec 草稿；Slides 可先生成可编辑提纲，再生成演示稿并根据提供的数据更新图表。这是新的正式可用范围，不重复上期的 Specs 编码工作流案例；原文未承诺所有连接器或 AI 用量免费。
值得看：可直接借鉴“保留依据—汇总决策、待办和未决问题—人工修改—生成交付物”的顺序。无需马上迁移工具；在现有 Markdown 里也能先执行，图表数字、遗漏意见和负责人仍应逐项人工核对。
Figma 官方可用范围与工作流（11 月 23 日）
10. Self-WSP 论文：小模型可以改自己的权重，但收益不等于理解了自己
CMU 与 MilkThink 作者于 11 月 21 日 14:36 UTC（北京时间 22:36）提交 Self-WSP。Qwen3.5-0.8B 在固定外部筛选循环中读取并编辑自身权重；作者报告精选模型的 GSM8K 准确率由 11.8% 升至 62.2%，MATH500 由 7.0% 升至 32.2%。论文同时发现大量无效提议、解释与实际编辑不符、保留修改也可能降低验证表现，随机搜索在部分设置下可比。上述最高结果不是普通单次运行的平均收益，也不证明已实现稳定递归自我改进。
值得看：读自我改进新闻要同时看随机基线、训练与验证划分、选择了多少次运行，以及没挑选的普通运行结果。可复用的是外部验证与回滚机制，而不是允许生产模型自行覆盖权重；本条为窗口内研究补充，不包装成今日首发。
